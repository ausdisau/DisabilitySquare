What the broader market suggests
The current landscape breaks into a few distinct species 🧭

1. Care-labour marketplaces
These are the “Uber for support work” style platforms.

Mable is essentially a marketplace for paid disability and aged-care support, where users can post jobs or search support workers, negotiate rates, and book services. It now describes itself as the largest online platform for independent support workers, with 30M+ care hours delivered, 30k+ clients, and 23k+ independent workers. 

mobility goes further into operational tooling: browsing, booking, scheduling, live appointment tracking, compliance, plan management, invoicing, and auto time-stamped shifts. 

Lesson for MapAble: this is the transactional spine, but not the whole body. It solves staffing and scheduling, not loneliness, belonging, or local community discovery. That gap is your opening. 

2. Companionship and social-connection platforms
These are closer to the “Rent a Human, but human and ethical” zone.

Like Family explicitly frames itself around reducing social isolation through “social carers” and companionship, social support, outings, hobbies, household help, and community access. Its platform terms say it is a marketplace connecting members with independent carers for non-medical care and companionship. 

Alvie is even more direct: a disability-focused social platform built around friendship, interest-based matching, police checks, carers/family inclusion, and NDIS-claimable participation. It positions itself as a safe space for people with disability to make friends and combat loneliness. 

Inclusee shows the non-profit/community version: online friendship, conversation, digital participation, and specialised programs designed to reduce isolation. 

Lesson for MapAble: there is real demand for platforms where the “service” is not just care tasks, but being with someone, doing life together, and helping people get back into the social bloodstream. 

3. Volunteer and micro-help networks
These are not marketplaces in the Gumtree sense, but they prove people will use tech for quick relational help.

Be My Eyes connects blind or low-vision users with volunteers and companies via live video and AI, and says it has more than 10 million volunteers and nearly 1 million users globally. Its help materials say volunteers are available 24/7 in more than 185 languages. 

Lesson for MapAble: not every need should become a paid shift. Some needs are tiny, urgent, social, or confidence-building. A healthy ecosystem blends paid support, peer help, and volunteer/community layers. 

4. Accessibility discovery platforms
These are “marketplace-adjacent” because they help people decide where they can go and what they can do.

AccessNow and Wheelmap are strong examples of community-generated accessibility data and place discovery. Your internal analysis already recognizes that these models create engagement and trust, but lack transactions. 


That matters because MapAble’s own advantage is the bridge between information and action: not just “is this venue accessible?” but “can I go there with the right support, the right transport, and maybe the right social match?” 

 


Why this matters so much
This is not a cute side feature. It is a response to a serious need.

The Australian Institute of Health and Welfare reports that in 2021, 19% of people with disability aged 15 to 64 experienced social isolation, versus 9.5% of people without disability. It also reports that 29% of people with disability aged 15 to 64 experienced loneliness, rising to 38% among people with severe or profound disability. 

So the product thesis is strong:

People are not only looking for care. They are looking for connection, confidence, participation, and a way back into ordinary life. 🌱

MapAble Peer Support Shared Decision-Making Framework
Purpose

Lived experience is treated as a valid and valuable form of knowledge.

Technology, peers, family, and workers support decision-making rather than replacing it.

plain language

step-by-step flows

reviews

safety monitoring

noticing patterns

Advocacy is embedded into normal use, not only triggered in crisis.

How It Works in Practice
Stage 1: Clarify the decision
The LLM helps the user identify:

what they are trying to do

what matters most

what worries them

what support they want in making the choice

Example:

“I need help getting to a new art group, but I’m nervous about going with someone I don’t know.”

The system identifies:

transport need

social participation goal

trust/safety concern

companionship preference

emotional confidence barrier

Stage 2: Generate options
The system offers options such as:

a support worker

a peer companion

a volunteer buddy

a small group option

transport alternatives

attending first with a known supporter

The key is not dumping a directory on the user. It curates options in a way that supports thought.

Stage 3: Peer-supported reflection
The user may choose to:

read peer notes

see lived-experience tips

ask a peer navigator

invite a trusted supporter into the decision flow

This is the bridge from machine recommendation to human confidence.

Stage 4: Shared decision capture
The decision is recorded in a lightweight, accessible way:

chosen option

why it suits the person

any worries or conditions

who is involved

fallback plan

review date

This becomes a living preference record, not a static intake form.

Stage 5: Safeguarded execution
Once a decision is made, the agentic system helps carry it out while monitoring risk:

confirm worker/companion

check timing and route

verify accessibility

send reminders

surface any anomalies

offer an easy “something feels wrong” option

Stage 6: Review and advocacy loop
After the event or support interaction, the system asks:

Did this feel right?

Did you feel respected?

Did you feel heard?

Would you choose this again?

Do you want help raising an issue?

Now the platform becomes a self-advocacy muscle-builder.

w(os.path.join(api_dir, "app", "services", "pricing.py"), """
from __future__ import annotations
from dataclasses import dataclass
from typing import Any, Dict, List

DEFAULT_RATE_CARD = {
    "base_fare": 8.0,
    "per_km": 2.2,
    "per_min": 0.55,
    "wheelchair_surcharge": 12.0,
    "driver_assistance_surcharge": 6.0,
    "booking_fee": 2.0,
    "min_fare": 18.0
}

def compute_price_km_min(distance_km: float, duration_min: float, access_needs: List[str], rate_card: Dict[str, Any] | None = None) -> float:
    rc = {**DEFAULT_RATE_CARD, **(rate_card or {})}
    price = rc["base_fare"] + (distance_km * rc["per_km"]) + (duration_min * rc["per_min"]) + rc["booking_fee"]

    if "wheelchair" in access_needs:
        price += rc.get("wheelchair_surcharge", 0.0)
    if "driver_assistance" in access_needs:
        price += rc.get("driver_assistance_surcharge", 0.0)

    return max(price, rc.get("min_fare", 0.0))
""")

from __future__ import annotations
from sqlalchemy.orm import Session
from sqlalchemy import select, func
from typing import Any, Dict, List, Tuple
from app.models.provider import ProviderOrg, Vehicle
from app.services.pricing import compute_price_km_min

def _has_required_features(vehicle_features: Dict[str, Any], access_needs: List[str]) -> bool:
    # Basic mapping. Extend as your taxonomy grows.
    # access_needs: ["wheelchair","ramp","hoist","driver_assistance"]
    if "wheelchair" in access_needs:
        # require ramp or hoist or tie_downs etc.
        if not (vehicle_features.get("ramp") or vehicle_features.get("hoist") or vehicle_features.get("wheelchair_access")):
            return False
    if "ramp" in access_needs and not vehicle_features.get("ramp"):
        return False
    if "hoist" in access_needs and not vehicle_features.get("hoist"):
        return False
    return True

def find_options(
    db: Session,
    pickup_point_wkt: str,
    access_needs: List[str],
    companions: int,
    radius_m: int = 8000
) -> List[Tuple[ProviderOrg, Vehicle, float]]:
    """
    Returns a list of (provider, vehicle, distance_m) candidates near pickup.
    pickup_point_wkt should be ST_GeogFromText('POINT(lng lat)') compatible string via GeoAlchemy.
    """
    # Filter vehicles that have last_location and match features/capacity.
    # Distance: ST_Distance(vehicles.last_location, pickup)
    pickup = func.ST_GeogFromText(pickup_point_wkt)

    stmt = (
        select(ProviderOrg, Vehicle, func.ST_Distance(Vehicle.last_location, pickup).label("distance_m"))
        .join(Vehicle, Vehicle.provider_id == ProviderOrg.id)
        .where(Vehicle.is_active == True)
        .where(Vehicle.last_location.is_not(None))
        .where(func.ST_DWithin(Vehicle.last_location, pickup, radius_m))
        .where(Vehicle.capacity_passengers >= (companions + 1))
        .order_by("distance_m")
        .limit(20)
    )

    rows = db.execute(stmt).all()
    out: List[Tuple[ProviderOrg, Vehicle, float]] = []
    for provider, vehicle, distance_m in rows:
        if _has_required_features(vehicle.features or {}, access_needs):
            out.append((provider, vehicle, float(distance_m)))
    return out

def build_quote_options(
    candidates: List[Tuple[ProviderOrg, Vehicle, float]],
    distance_km_est: float,
    duration_min_est: float,
    access_needs: List[str],
) -> List[dict]:
    """
    Convert candidates into quote options. Distance/duration here are trip distance estimates,
    not pickup distance. In production, plug in Google Directions / GTFS / your own router.
    """
    options = []
    for provider, vehicle, pickup_distance_m in candidates:
        price = compute_price_km_min(distance_km_est, duration_min_est, access_needs, provider.rate_card or None)
        # crude ETA: pickup travel time + a buffer
        eta_min = max(5, int((pickup_distance_m / 1000.0) / 0.45))  # assume ~27km/h
        notes = []
        if provider.supports_ndis:
            notes.append("NDIS supported")
        if provider.external_system:
            notes.append(f"Routed via {provider.external_system}")
        options.append({
            "provider_id": provider.id,
            "provider_name": provider.name,
            "provider_kind": provider.kind,
            "vehicle_id": vehicle.id,
            "vehicle_type": vehicle.vehicle_type,
            "eta_minutes": eta_min,
            "price_amount": round(float(price), 2),
            "currency": "AUD",
            "notes": "; ".join(notes),
        })
    return options
""")

from __future__ import annotations
from dataclasses import dataclass
from typing import Protocol, Optional, Dict, Any

@dataclass
class ExternalBookingResult:
    external_booking_ref: str
    status: str  # confirmed/pending/failed
    raw: Dict[str, Any] | None = None

class ProviderAdapter(Protocol):
    async def book(self, payload: Dict[str, Any]) -> ExternalBookingResult: ...
    async def cancel(self, external_booking_ref: str) -> bool: ...

class AdapterRegistry:
    def __init__(self):
        self._adapters: dict[str, ProviderAdapter] = {}

    def register(self, key: str, adapter: ProviderAdapter):
        self._adapters[key] = adapter

    def get(self, key: str) -> ProviderAdapter:
        if key not in self._adapters:
            raise KeyError(f"No adapter registered for '{key}'")
        return self._adapters[key]
""")

def _wkt_point(lat: float, lng: float) -> str:
    return f"POINT({lng} {lat})"

@router.post("/trips/quote", response_model=TripQuoteResponse)
async def quote_trip(payload: TripQuoteRequest, db: Session = Depends(get_db)):
    quote_id = str(uuid.uuid4())

    # Persist quote
    q = TripQuote(
        id=quote_id,
        user_id="demo-user",  # Replace with MapAble Core JWT subject
        pickup=point_from_latlng(payload.pickup.lat, payload.pickup.lng),
        dropoff=point_from_latlng(payload.dropoff.lat, payload.dropoff.lng),
        pickup_window_minutes=payload.pickup_window_minutes,
        requested_pickup_at=payload.requested_pickup_at,
        access_needs=payload.access_needs,
        mobility_aids=payload.mobility_aids,
        companions=payload.companions,
        funding=payload.funding,
    )

    # Step 1: find nearby candidates (vehicles/providers) based on pickup
    candidates = find_options(
        db=db,
        pickup_point_wkt=_wkt_point(payload.pickup.lat, payload.pickup.lng),
        access_needs=payload.access_needs,
        companions=payload.companions,
        radius_m=12000
    )

    # Step 2: estimate trip distance/duration (MVP stub)
    # Plug in Google Directions / your router here.
    # We'll use a rough heuristic: 8km and 20 min.
    distance_km_est = float(payload.funding.get("distance_km_est", 8.0))
    duration_min_est = float(payload.funding.get("duration_min_est", 20.0))

    options_raw = build_quote_options(candidates, distance_km_est, duration_min_est, payload.access_needs)

    # Attach stable option_id for selection
    options = []
    for o in options_raw:
        o["option_id"] = str(uuid.uuid4())
        options.append(o)

    q.options = options
    db.add(q)
    db.commit()

    return TripQuoteResponse(
        quote_id=quote_id,
        options=[
            TripOption(
                option_id=o["option_id"],
                provider_id=o["provider_id"],
                provider_name=o["provider_name"],
                provider_kind=o["provider_kind"],
                vehicle_type=o["vehicle_type"],
                eta_minutes=o["eta_minutes"],
                price={"amount": o["price_amount"], "currency": o["currency"]},
                notes=o.get("notes","")
            )
            for o in options
        ]
    )

@router.post("/trips", response_model=TripResponse)
async def create_trip(payload: TripCreateRequest, db: Session = Depends(get_db)):
    quote = db.execute(select(TripQuote).where(TripQuote.id == payload.quote_id)).scalar_one_or_none()
    if not quote:
        raise HTTPException(status_code=404, detail="Quote not found")

    selected = next((o for o in (quote.options or []) if o.get("option_id") == payload.option_id), None)
    if not selected:
        raise HTTPException(status_code=400, detail="Invalid option_id for quote")

    trip_id = str(uuid.uuid4())

    t = Trip(
        id=trip_id,
        user_id=quote.user_id,
        provider_id=selected["provider_id"],
        vehicle_id=selected.get("vehicle_id"),
        pickup=quote.pickup,
        dropoff=quote.dropoff,
        pickup_address=payload.pickup_address,
        dropoff_address=payload.dropoff_address,
        pickup_window_minutes=quote.pickup_window_minutes,
        requested_pickup_at=quote.requested_pickup_at,
        access_needs=quote.access_needs,
        mobility_aids=quote.mobility_aids,
        companions=quote.companions,
        funding=quote.funding,
        price=selected["price_amount"],
        currency=selected["currency"],
        status=TripStatus.pending_provider_confirmation,
    )

    db.add(t)
    db.commit()

    # Dispatch to provider adapter (async, MVP runs inline)
    provider = db.execute(select(ProviderOrg).where(ProviderOrg.id == t.provider_id)).scalar_one_or_none()
    if not provider:
        t.status = TripStatus.failed
        db.commit()
        raise HTTPException(status_code=500, detail="Provider missing")

    adapter_key = provider.external_system or "fleet"
    try:
        adapter = registry.get(adapter_key)
    except KeyError:
        adapter = registry.get("fleet")

    booking_payload = {
        "trip_id": t.id,
        "pickup": quote.funding.get("pickup_human", payload.pickup_address),
        "dropoff": quote.funding.get("dropoff_human", payload.dropoff_address),
        "requested_pickup_at": (quote.requested_pickup_at.isoformat() if quote.requested_pickup_at else None),
        "pickup_window_minutes": quote.pickup_window_minutes,
        "access_needs": quote.access_needs,
        "mobility_aids": quote.mobility_aids,
        "companions": quote.companions,
        "funding": quote.funding,
        "pickup_notes": payload.pickup_notes
    }

    result = await adapter.book(booking_payload)
    t.external_booking_ref = result.external_booking_ref
    t.status = TripStatus.confirmed if result.status == "confirmed" else TripStatus.pending_provider_confirmation
    db.commit()

    return TripResponse(
        trip_id=t.id,
        status=t.status.value,
        provider_id=t.provider_id,
        vehicle_id=t.vehicle_id,
        driver_id=t.driver_id,
        price={"amount": float(t.price) if t.price is not None else None, "currency": t.currency} if t.price is not None else None,
        external_booking_ref=t.external_booking_ref
    )

# MapAble Transport Search + Booking (MVP)

This is a small, runnable backend that implements an **Uber-style quote + book flow** for **accessible transport**.

It’s designed to plug into the MapAble ecosystem:
- A POST /transport/trips/quote endpoint that returns *options* (provider + vehicle class + price + ETA).
- A POST /transport/trips endpoint that books a chosen option via a **provider adapter** (mock “Zoomly-style” + mock “Fleet”).
- A GET /transport/trips/{id} endpoint to read booking status.
- A POST /transport/trips/{id}/cancel endpoint.

from typing import Any, Dict, List
DEFAULT_RATE_CARD = {"base_fare": 8.0, "per_km": 2.2, "per_min": 0.55, "wheelchair_surcharge": 12.0, "driver_assistance_surcharge": 6.0, "booking_fee": 2.0, "min_fare": 18.0}
def compute_price(distance_km: float, duration_min: float, access_needs: List[str], rate_card: Dict[str, Any] | None = None) -> float:
    rc = {**DEFAULT_RATE_CARD, **(rate_card or {})}
    price = rc["base_fare"] + distance_km*rc["per_km"] + duration_min*rc["per_min"] + rc["booking_fee"]
    if "wheelchair" in access_needs: price += rc.get("wheelchair_surcharge", 0.0)
    if "driver_assistance" in access_needs: price += rc.get("driver_assistance_surcharge", 0.0)
    return max(price, rc.get("min_fare", 0.0))

from sqlalchemy.orm import Session
from sqlalchemy import select, func
from typing import Any, Dict, List, Tuple
from app.models.provider import ProviderOrg, Vehicle
from app.services.pricing import compute_price

def vehicle_ok(features: Dict[str, Any], access_needs: List[str]) -> bool:
    if "wheelchair" in access_needs and not (features.get("ramp") or features.get("hoist") or features.get("wheelchair_access")):
        return False
    if "ramp" in access_needs and not features.get("ramp"):
        return False
    return True

def find_candidates(db: Session, pickup_wkt: str, access_needs: List[str], companions: int, radius_m: int = 12000):
    pickup = func.ST_GeogFromText(pickup_wkt)
    stmt = (
        select(ProviderOrg, Vehicle, func.ST_Distance(Vehicle.last_location, pickup).label("distance_m"))
        .join(Vehicle, Vehicle.provider_id == ProviderOrg.id)
        .where(Vehicle.is_active == True)
        .where(Vehicle.last_location.is_not(None))
        .where(func.ST_DWithin(Vehicle.last_location, pickup, radius_m))
        .where(Vehicle.capacity_passengers >= (companions + 1))
        .order_by("distance_m")
        .limit(20)
    )
    rows = db.execute(stmt).all()
    out = []
    for provider, vehicle, dist in rows:
        if vehicle_ok(vehicle.features or {}, access_needs):
            out.append((provider, vehicle, float(dist)))
    return out

def build_options(candidates, distance_km_est: float, duration_min_est: float, access_needs: List[str]):
    options = []
    for provider, vehicle, pickup_dist_m in candidates:
        price = compute_price(distance_km_est, duration_min_est, access_needs, provider.rate_card or None)
        eta = max(5, int((pickup_dist_m/1000.0)/0.45))
        options.append({
            "provider_id": provider.id, "provider_name": provider.name, "provider_kind": provider.kind,
            "vehicle_id": vehicle.id, "vehicle_type": vehicle.vehicle_type,
            "eta_minutes": eta, "price_amount": round(float(price),2), "currency":"AUD",
            "notes": ("NDIS supported" if provider.supports_ndis else "")
        })
    return options

import fp from 'fastify-plugin';
import createError from 'http-errors';
import { createRemoteJWKSet, jwtVerify } from 'jose';

declare module 'fastify' {
  interface FastifyRequest {
    auth: {
      sub: string;
      roles: string[];
    };
  }
}

function getBearer(req: any): string | null {
  const h = req.headers?.authorization;
  if (!h || typeof h !== 'string') return null;
  const m = h.match(/^Bearer\\s+(.+)$/i);
  return m?.[1] ?? null;
}

export const authPlugin = fp(async (app) => {
  const jwksUrl = process.env.JWKS_URL;
  const audience = process.env.JWT_AUDIENCE;
  const issuer = process.env.JWT_ISSUER;

  if (!jwksUrl || !audience || !issuer) {
    app.log.warn('Auth disabled: JWKS_URL/JWT_AUDIENCE/JWT_ISSUER not set. All requests will be treated as demo-user.');
  }

  const jwks = jwksUrl ? createRemoteJWKSet(new URL(jwksUrl)) : null;

  // Default auth hook for all non-webhook routes
  app.addHook('preHandler', async (req, _reply) => {
    if (req.routerPath?.startsWith('/webhooks')) return;

    if (!jwks || !audience || !issuer) {
      req.auth = { sub: 'demo-user', roles: ['participant'] };
      return;
    }

    const token = getBearer(req);
    if (!token) throw new createError.Unauthorized('Missing Bearer token');

    const { payload } = await jwtVerify(token, jwks, { audience, issuer });

    const sub = String(payload.sub ?? '');
    if (!sub) throw new createError.Unauthorized('Missing sub');

    // Roles can come from custom claims in Auth0 / MapAble Core. Adjust as needed.
    const roles =
      (payload['https://mapable.app/roles'] as string[] | undefined) ??
      (payload['roles'] as string[] | undefined) ??
      ['participant'];

    req.auth = { sub, roles };
  });
});
""")

export function haversineKm(a: { lat: number; lng: number }, b: { lat: number; lng: number }) {
  const R = 6371;
  const toRad = (x: number) => (x * Math.PI) / 180;
  const dLat = toRad(b.lat - a.lat);
  const dLng = toRad(b.lng - a.lng);
  const lat1 = toRad(a.lat);
  const lat2 = toRad(b.lat);

  const s =
    Math.sin(dLat / 2) ** 2 +
    Math.cos(lat1) * Math.cos(lat2) * Math.sin(dLng / 2) ** 2;

  return 2 * R * Math.asin(Math.min(1, Math.sqrt(s)));
}

export function estimateDurationMin(distanceKm: number) {
  // conservative average: 24 km/h + 4 min buffer for pickup load/unload
  return Math.max(8, Math.round((distanceKm / 24) * 60 + 4));
}
""")

    rc.base_fare + distanceKm * rc.per_km + durationMin * rc.per_min + rc.booking_fee;

}

import type { PrismaClient, Provider, Vehicle } from '@prisma/client';

/**
 * Find nearby candidate vehicles.
 * Uses PostGIS if available (recommended: you're already running postgis/postgis in docker-compose).
 *
 * We store lastLat/lastLng on Vehicle; we compute distance using ST_DWithin with geography points.
 */
export async function findCandidateVehicles(params: {
  prisma: PrismaClient;
  pickup: { lat: number; lng: number };
  companions: number;
  radiusM: number;
}) {
  const { prisma, pickup, companions, radiusM } = params;

  // Raw query because Prisma doesn't (yet) give great ergonomics for geography distance.
  const rows = await prisma.$queryRawUnsafe<
    Array<{
      providerId: string;
      providerName: string;
      providerKind: string;
      externalSystem: string | null;
      supportsNdis: boolean;
      bookingMode: string;
      rateCard: any;
      vehicleId: string;
      vehicleType: string;
      features: any;
      capacityPassengers: number;
      capacityWheelchairs: number;
      distanceM: number;
    }>
  >(
    
    SELECT
      p.id as "providerId",
      p.name as "providerName",
      p.kind::text as "providerKind",
      p."externalSystem" as "externalSystem",
      p."supportsNdis" as "supportsNdis",
      p."bookingMode"::text as "bookingMode",
      p."rateCard" as "rateCard",
      v.id as "vehicleId",
      v."vehicleType" as "vehicleType",
      v.features as "features",
      v."capacityPassengers" as "capacityPassengers",
      v."capacityWheelchairs" as "capacityWheelchairs",
      ST_Distance(
        ST_SetSRID(ST_MakePoint(v."lastLng", v."lastLat"), 4326)::geography,
        ST_SetSRID(ST_MakePoint($1, $2), 4326)::geography
      ) as "distanceM"
    FROM "Vehicle" v
    JOIN "Provider" p ON p.id = v."providerId"
    WHERE
      v.status = 'available'
      AND v."lastLat" IS NOT NULL AND v."lastLng" IS NOT NULL
      AND v."capacityPassengers" >= $3
      AND ST_DWithin(
        ST_SetSRID(ST_MakePoint(v."lastLng", v."lastLat"), 4326)::geography,
        ST_SetSRID(ST_MakePoint($1, $2), 4326)::geography,
        $4
      )
    ORDER BY "distanceM" ASC
    LIMIT 25;
    ,
    pickup.lng,
    pickup.lat,
    companions + 1,
    radiusM,
  );

  return rows;
}

export function vehicleMeetsAccessNeeds(features: any, accessNeeds: string[]) {
  const f = features ?? {};
  if (accessNeeds.includes('wheelchair')) {
    if (!(f.ramp || f.hoist || f.wheelchair_access || f.wheelchairAccess)) return false;
  }
  if (accessNeeds.includes('ramp') && !f.ramp) return false;
  if (accessNeeds.includes('hoist') && !f.hoist) return false;
  return true;
}

import createError from 'http-errors';

type UberToken = { access_token: string; expires_in: number; token_type: string };

export class UberGuestRidesClient {
  constructor(
    private cfg: {
      baseUrl: string;
      clientId: string;
      clientSecret: string;
      orgUuid: string;
    },
  ) {}

  private token: { value: string; expiresAt: number } | null = null;

  private async getToken() {
    const now = Date.now();
    if (this.token && this.token.expiresAt > now + 30_000) return this.token.value;

    const url = ${this.cfg.baseUrl}/oauth/v2/token;
    const body = new URLSearchParams({
      grant_type: 'client_credentials',
      client_id: this.cfg.clientId,
      client_secret: this.cfg.clientSecret,
      scope: 'guest_trips',
    });

    const r = await fetch(url, {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body,
    });

    if (!r.ok) {
      throw new createError.BadGateway(Uber token request failed: ${r.status});
    }

    const json = (await r.json()) as UberToken;
    const expiresAt = now + json.expires_in * 1000;
    this.token = { value: json.access_token, expiresAt };
    return json.access_token;
  }

  async createGuestTrip(payload: any) {
    const token = await this.getToken();
    const url = ${this.cfg.baseUrl}/v1/guests/trips; // check exact path in Uber docs / Postman collection
    const r = await fetch(url, {
      method: 'POST',
      headers: {
        Authorization: Bearer ${token},
        'Content-Type': 'application/json',
        'x-uber-organizationuuid': this.cfg.orgUuid,
      },
      body: JSON.stringify(payload),
    });

    if (!r.ok) {
      const text = await r.text().catch(() => '');
      throw new createError.BadGateway(Uber create trip failed: ${r.status} ${text});
    }

    return r.json();
  }
}

import createError from 'http-errors';
import { z } from 'zod';
import { computePrice } from './pricing.js';
import { estimateDurationMin, haversineKm } from './routing/haversine.js';

function nowPlusMinutes(min: number) {
  return new Date(Date.now() + min * 60_000);
}

export function transportService(app: FastifyInstance) {
  return {
    async quote(userSub: string, payload: unknown) {
      const parsed = TripQuoteRequest.parse(payload);

      // Ensure user exists
      const user = await app.prisma.user.upsert({
        where: { authSub: userSub },
        update: {},
        create: { authSub: userSub, role: 'participant' },
      });

      // Distance/duration (replace with Google Directions when ready)
      const distKm = parsed.funding.distance_km_est ?? haversineKm(parsed.pickup, parsed.dropoff);
      const durMin = parsed.funding.duration_min_est ?? estimateDurationMin(distKm);

      const candidates = await findCandidateVehicles({
        prisma: app.prisma,
        pickup: parsed.pickup,
        companions: parsed.companions,
        radiusM: 12_000,
      });

      const options = candidates
        .filter((c) => vehicleMeetsAccessNeeds(c.features, parsed.access_needs))
        .map((c) => {
          const price = computePrice(distKm, durMin, parsed.access_needs, c.rateCard);
          const etaMinutes = Math.max(5, Math.round((c.distanceM / 1000 / 0.45) * 1)); // ~27km/h
          const service_level = c.supportsNdis || String(c.bookingMode) === 'manual_dispatch' ? 'supportive' : 'standard';

          return {
            option_id: crypto.randomUUID(),
            provider_id: c.providerId,
            provider_name: c.providerName,
            provider_kind: c.providerKind,
            service_level,
            vehicle_type: c.vehicleType,
            eta_minutes: etaMinutes,
            price_amount: price,
            currency: 'AUD',
            notes: c.supportsNdis ? 'NDIS supported' : '',
            _vehicle_id: c.vehicleId, // internal, stripped before returning
            _adapter_key: c.externalSystem ?? 'zoomly_manual',
          };
        })
        .slice(0, 10);

      const expiresAt = nowPlusMinutes(15);

      const quote = await app.prisma.tripQuote.create({
        data: {
          userId: user.id,
          payload: parsed,
          options,
          expiresAt,
        },
      });

      // return typed response (strip internal fields)
      const clean = options.map(({ _vehicle_id, _adapter_key, ...rest }) => rest);

      return TripQuoteResponse.parse({
        quote_id: quote.id,
        expires_at: expiresAt.toISOString(),
        options: clean,
      });
    },

    async book(userSub: string, payload: unknown) {
      const parsed = TripCreateRequest.parse(payload);

      const user = await app.prisma.user.findUnique({ where: { authSub: userSub } });
      if (!user) throw new createError.Unauthorized('Unknown user');

      const quote = await app.prisma.tripQuote.findFirst({
        where: { id: parsed.quote_id, userId: user.id },
      });
      if (!quote) throw new createError.NotFound('Quote not found');
      if (new Date(quote.expiresAt).getTime() < Date.now()) throw new createError.Gone('Quote expired');

      const options = z.array(z.any()).parse(quote.options ?? []);
      const selected = options.find((o) => o.option_id === parsed.option_id);
      if (!selected) throw new createError.BadRequest('Invalid option_id');

      const trip = await app.prisma.trip.create({
        data: {
          userId: user.id,
          providerId: selected.provider_id,
          vehicleId: selected._vehicle_id ?? null,
          status: 'pending_provider_confirmation',
          pickupLat: String((quote.payload as any).pickup.lat),
          pickupLng: String((quote.payload as any).pickup.lng),
          dropoffLat: String((quote.payload as any).dropoff.lat),
          dropoffLng: String((quote.payload as any).dropoff.lng),
          pickupAddress: parsed.pickup_address ?? null,
          dropoffAddress: parsed.dropoff_address ?? null,
          requestedPickupAt: (quote.payload as any).requested_pickup_at ? new Date((quote.payload as any).requested_pickup_at) : null,
          pickupWindowMin: (quote.payload as any).pickup_window_minutes ?? 20,
          accessNeeds: (quote.payload as any).access_needs ?? [],
          mobilityAids: (quote.payload as any).mobility_aids ?? [],
          companions: (quote.payload as any).companions ?? 0,
          funding: (quote.payload as any).funding ?? {},
          priceAmount: String(selected.price_amount),
          currency: selected.currency ?? 'AUD',
          events: {
            create: { type: 'TRIP_CREATED', payload: { quote_id: quote.id, option_id: parsed.option_id } },
          },
        },
      });

      // Dispatch to provider adapter
      const adapterKey = selected._adapter_key ?? 'zoomly_manual';
      if (!registry.has(adapterKey)) {
        // fall back to manual dispatch
        app.log.warn({ adapterKey }, 'Unknown adapter. Falling back to manual dispatch.');
      }
      const adapter = registry.has(adapterKey) ? registry.get(adapterKey) : registry.get('zoomly_manual');

      const booking = await adapter.book({
        tripId: trip.id,
        pickup: { lat: Number((quote.payload as any).pickup.lat), lng: Number((quote.payload as any).pickup.lng), address: parsed.pickup_address },
        dropoff: { lat: Number((quote.payload as any).dropoff.lat), lng: Number((quote.payload as any).dropoff.lng), address: parsed.dropoff_address },
        requestedPickupAt: (quote.payload as any).requested_pickup_at,

        pickupNotes: parsed.pickup_notes,
        rider: { phone: user.phone ?? undefined, name: user.email ?? undefined },
      });

      const nextStatus = booking.status === 'confirmed' ? 'confirmed' : 'pending_provider_confirmation';
      assertTransition(trip.status, nextStatus);

      const updated = await app.prisma.trip.update({

        data: {
          status: nextStatus,
          externalBookingRef: booking.externalBookingRef,
          events: {
            create: { type: 'PROVIDER_BOOKED', payload: booking.raw ?? {} },
          },
        },
      });

      return TripResponse.parse({
        trip_id: updated.id,
        status: updated.status,
        provider_id: updated.providerId ?? null,
        vehicle_id: updated.vehicleId ?? null,
        driver_id: null,

import { z } from 'zod';

export const LatLng = z.object({
  lat: z.number().min(-90).max(90),
  lng: z.number().min(-180).max(180),
});

export const AccessNeed = z.enum([
  'wheelchair',
  'ramp',
  'hoist',
  'driver_assistance',
  'low_sensory',
  'quiet_driver',
  'no_stairs',
]);

export const MobilityAid = z.enum(['manual_chair', 'power_chair', 'walker', 'cane', 'other']);

export const Funding = z
  .object({
    type: z.enum(['ndis', 'self_pay', 'other']).default('self_pay'),
    plan_managed: z.boolean().optional(),
    ndia_managed: z.boolean().optional(),
    self_managed: z.boolean().optional(),
    plan_manager_name: z.string().optional(),
    distance_km_est: z.number().positive().optional(),
    duration_min_est: z.number().positive().optional(),
  })
  .passthrough();

export const TripQuoteRequest = z.object({
  pickup: LatLng,
  dropoff: LatLng,
  requested_pickup_at: z.string().datetime().optional(),
  pickup_window_minutes: z.number().int().min(5).max(180).default(20),
  access_needs: z.array(AccessNeed).default([]),
  mobility_aids: z.array(MobilityAid).default([]),
  companions: z.number().int().min(0).max(6).default(0),
  funding: Funding.default({ type: 'self_pay' }),
});

export const TripOption = z.object({
  option_id: z.string().uuid(),
  provider_id: z.string().uuid(),
  provider_name: z.string(),
  provider_kind: z.string(),
  service_level: z.enum(['standard', 'supportive']).default('standard'),
  vehicle_type: z.string(),
  eta_minutes: z.number().int().min(1),
  price_amount: z.number().nonnegative(),
  currency: z.string().default('AUD'),
  notes: z.string().default(''),
});

export const TripQuoteResponse = z.object({
  quote_id: z.string().uuid(),
  expires_at: z.string().datetime(),
  options: z.array(TripOption),
});

export const TripCreateRequest = z.object({
  quote_id: z.string().uuid(),
  option_id: z.string().uuid(),
  pickup_address: z.string().max(400).optional(),
  dropoff_address: z.string().max(400).optional(),
  pickup_notes: z.string().max(800).optional(),
});

export const TripResponse = z.object({

  provider_id: z.string().uuid().nullable(),
  vehicle_id: z.string().uuid().nullable(),
  driver_id: z.string().uuid().nullable(),

import fp from 'fastify-plugin';
import createError from 'http-errors';
import { createRemoteJWKSet, jwtVerify } from 'jose';

declare module 'fastify' {
  interface FastifyRequest {
    auth: { sub: string; roles: string[] };
  }
}

function bearer(req: any): string | null {
  const h = req.headers?.authorization;
  if (!h || typeof h !== 'string') return null;
  const m = h.match(/^Bearer\s+(.+)$/i);
  return m?.[1] ?? null;
}

export const authPlugin = fp(async (app) => {
  const jwksUrl = process.env.JWKS_URL;
  const audience = process.env.JWT_AUDIENCE;
  const issuer = process.env.JWT_ISSUER;

  if (!jwksUrl || !audience || !issuer) {
    app.log.warn('Auth disabled (missing JWKS_URL/JWT_AUDIENCE/JWT_ISSUER). Using demo-user.');
  }

  const jwks = jwksUrl ? createRemoteJWKSet(new URL(jwksUrl)) : null;

  app.addHook('preHandler', async (req) => {
    if (req.routerPath?.startsWith('/webhooks')) return;

    if (!jwks || !audience || !issuer) {
      req.auth = { sub: 'demo-user', roles: ['participant'] };
      return;
    }

    const t = bearer(req);
    if (!t) throw new createError.Unauthorized('Missing Bearer token');

    const { payload } = await jwtVerify(t, jwks, { audience, issuer });

    const sub = String(payload.sub ?? '');
    if (!sub) throw new createError.Unauthorized('Missing sub');

    const roles =
      (payload['https://mapable.app/roles'] as string[] | undefined) ??
      (payload['roles'] as string[] | undefined) ??
      ['participant'];

    req.auth = { sub, roles };
  });
});

export function haversineKm(a: { lat: number; lng: number }, b: { lat: number; lng: number }) {
  const R = 6371;
  const toRad = (x: number) => (x * Math.PI) / 180;
  const dLat = toRad(b.lat - a.lat);
  const dLng = toRad(b.lng - a.lng);
  const lat1 = toRad(a.lat);
  const lat2 = toRad(b.lat);

  const s =
    Math.sin(dLat / 2) ** 2 +
    Math.cos(lat1) * Math.cos(lat2) * Math.sin(dLng / 2) ** 2;

  return 2 * R * Math.asin(Math.min(1, Math.sqrt(s)));
}

export function estimateDurationMin(distanceKm: number) {
  return Math.max(8, Math.round((distanceKm / 24) * 60 + 4));
}

type RateCard = Record<string, any>;

const DEFAULT_RATE_CARD: RateCard = {
  base_fare: 8.0,
  per_km: 2.2,
  per_min: 0.55,
  wheelchair_surcharge: 12.0,
  driver_assistance_surcharge: 6.0,
  booking_fee: 2.0,
  min_fare: 18.0
};

export function computePrice(distanceKm: number, durationMin: number, accessNeeds: string[], rateCard?: RateCard) {
  const rc = { ...DEFAULT_RATE_CARD, ...(rateCard ?? {}) };
  let price = rc.base_fare + distanceKm * rc.per_km + durationMin * rc.per_min + rc.booking_fee;
  if (accessNeeds.includes('wheelchair')) price += rc.wheelchair_surcharge ?? 0;
  if (accessNeeds.includes('driver_assistance')) price += rc.driver_assistance_surcharge ?? 0;
  price = Math.max(price, rc.min_fare ?? 0);
  return Math.round(price * 100) / 100;
}

import type { PrismaClient } from '@prisma/client';

export async function findCandidateVehicles(params: {
  prisma: PrismaClient;
  pickup: { lat: number; lng: number };
  companions: number;
  radiusM: number;
}) {
  const { prisma, pickup, companions, radiusM } = params;

  // PostGIS radius search using lastLat/lastLng (recommended for speed + accuracy).
  const rows = await prisma.$queryRawUnsafe<
    Array<{
      providerId: string;
      providerName: string;
      providerKind: string;
      externalSystem: string | null;
      supportsNdis: boolean;
      bookingMode: string;
      rateCard: any;
      vehicleId: string;
      vehicleType: string;
      features: any;
      distanceM: number;
    }>
  >(
    `
    SELECT
      p.id as "providerId",
      p.name as "providerName",
      p.kind::text as "providerKind",
      p."externalSystem" as "externalSystem",
      p."supportsNdis" as "supportsNdis",
      p."bookingMode"::text as "bookingMode",
      p."rateCard" as "rateCard",
      v.id as "vehicleId",
      v."vehicleType" as "vehicleType",
      v.features as "features",
      ST_Distance(
        ST_SetSRID(ST_MakePoint(v."lastLng", v."lastLat"), 4326)::geography,
        ST_SetSRID(ST_MakePoint($1, $2), 4326)::geography
      ) as "distanceM"
    FROM "Vehicle" v
    JOIN "Provider" p ON p.id = v."providerId"
    WHERE
      v.status = 'available'
      AND v."lastLat" IS NOT NULL AND v."lastLng" IS NOT NULL
      AND v."capacityPassengers" >= $3
      AND ST_DWithin(
        ST_SetSRID(ST_MakePoint(v."lastLng", v."lastLat"), 4326)::geography,
        ST_SetSRID(ST_MakePoint($1, $2), 4326)::geography,
        $4
      )
    ORDER BY "distanceM" ASC
    LIMIT 25;
    `,
    pickup.lng,
    pickup.lat,
    companions + 1,
    radiusM,
  );

  return rows;
}

export function vehicleMeetsAccessNeeds(features: any, accessNeeds: string[]) {
  const f = features ?? {};
  if (accessNeeds.includes('wheelchair')) {
    if (!(f.ramp || f.hoist || f.wheelchair_access || f.wheelchairAccess)) return false;
  }
  if (accessNeeds.includes('ramp') && !f.ramp) return false;
  if (accessNeeds.includes('hoist') && !f.hoist) return false;
  return true;
}

import createError from 'http-errors';

type UberToken = { access_token: string; expires_in: number; token_type: string };

export class UberGuestRidesClient {
  constructor(
    private cfg: { baseUrl: string; clientId: string; clientSecret: string; orgUuid: string },
  ) {}

  private token: { value: string; expiresAt: number } | null = null;

  private async getToken() {
    const now = Date.now();
    if (this.token && this.token.expiresAt > now + 30_000) return this.token.value;

    const url = `${this.cfg.baseUrl}/oauth/v2/token`;
    const body = new URLSearchParams({
      grant_type: 'client_credentials',
      client_id: this.cfg.clientId,
      client_secret: this.cfg.clientSecret,
      scope: 'guest_trips',
    });

    const r = await fetch(url, {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body,
    });

    if (!r.ok) throw new createError.BadGateway(`Uber token request failed: ${r.status}`);

    const json = (await r.json()) as UberToken;
    this.token = { value: json.access_token, expiresAt: now + json.expires_in * 1000 };
    return json.access_token;
  }

  async createGuestTrip(payload: any) {
    const token = await this.getToken();

    // Verify exact endpoint in Uber docs/Postman for your account.
    const url = `${this.cfg.baseUrl}/v1/guests/trips`;

    const r = await fetch(url, {
      method: 'POST',
      headers: {
        Authorization: `Bearer ${token}`,
        'Content-Type': 'application/json',
        'x-uber-organizationuuid': this.cfg.orgUuid,
      },
      body: JSON.stringify(payload),
    });

    if (!r.ok) {
      const text = await r.text().catch(() => '');
      throw new createError.BadGateway(`Uber create trip failed: ${r.status} ${text}`);
    }

    return r.json();
  }
}

write apps/api/src/transport/service.ts <<'EOF'
import createError from 'http-errors';
import { z } from 'zod';
import { TripQuoteRequest, TripQuoteResponse, TripCreateRequest, TripResponse } from '@mapable/shared';
import { haversineKm, estimateDurationMin } from './haversine.js';
import { findCandidateVehicles, vehicleMeetsAccessNeeds } from './matching.js';
import { computePrice } from './pricing.js';
import { buildProviderRegistry } from '../providers/registry.js';
import type { FastifyInstance } from 'fastify';

const registry = buildProviderRegistry();

const plusMinutes = (m: number) => new Date(Date.now() + m * 60_000);

export function transportService(app: FastifyInstance) {
  return {
    async quote(userSub: string, body: unknown) {
      const parsed = TripQuoteRequest.parse(body);

      const user = await app.prisma.user.upsert({
        where: { authSub: userSub },
        update: {},
        create: { authSub: userSub, role: 'participant' },
      });

      const distKm = parsed.funding.distance_km_est ?? haversineKm(parsed.pickup, parsed.dropoff);
      const durMin = parsed.funding.duration_min_est ?? estimateDurationMin(distKm);

      const candidates = await findCandidateVehicles({
        prisma: app.prisma,
        pickup: parsed.pickup,
        companions: parsed.companions,
        radiusM: 12_000,
      });

      const options = candidates
        .filter((c) => vehicleMeetsAccessNeeds(c.features, parsed.access_needs))
        .map((c) => {
          const price = computePrice(distKm, durMin, parsed.access_needs, c.rateCard);
          const eta = Math.max(5, Math.round((c.distanceM / 1000 / 0.45) * 1));
          const service_level = c.supportsNdis || c.bookingMode === 'manual_dispatch' ? 'supportive' : 'standard';

          return {
            option_id: crypto.randomUUID(),
            provider_id: c.providerId,
            provider_name: c.providerName,
            provider_kind: c.providerKind,
            service_level,
            vehicle_type: c.vehicleType,
            eta_minutes: eta,
            price_amount: price,
            currency: 'AUD',
            notes: c.supportsNdis ? 'NDIS supported' : '',
            _vehicle_id: c.vehicleId,
            _adapter_key: c.externalSystem ?? 'zoomly_manual',
          };
        })
        .slice(0, 10);

      const expiresAt = plusMinutes(15);

      const quote = await app.prisma.tripQuote.create({
        data: { userId: user.id, payload: parsed, options, expiresAt },
      });

      const clean = options.map(({ _vehicle_id, _adapter_key, ...rest }) => rest);

      return TripQuoteResponse.parse({
        quote_id: quote.id,
        expires_at: expiresAt.toISOString(),
        options: clean,
      });
    },

    async book(userSub: string, body: unknown) {
      const parsed = TripCreateRequest.parse(body);

      const user = await app.prisma.user.findUnique({ where: { authSub: userSub } });
      if (!user) throw new createError.Unauthorized('Unknown user');

      const quote = await app.prisma.tripQuote.findFirst({ where: { id: parsed.quote_id, userId: user.id } });
      if (!quote) throw new createError.NotFound('Quote not found');
      if (new Date(quote.expiresAt).getTime() < Date.now()) throw new createError.Gone('Quote expired');

      const options = z.array(z.any()).parse(quote.options ?? []);
      const selected = options.find((o) => o.option_id === parsed.option_id);
      if (!selected) throw new createError.BadRequest('Invalid option_id');

      const payload = quote.payload as any;

      const trip = await app.prisma.trip.create({
        data: {
          userId: user.id,
          providerId: selected.provider_id,
          vehicleId: selected._vehicle_id ?? null,
          status: 'pending_provider_confirmation',
          pickupLat: String(payload.pickup.lat),
          pickupLng: String(payload.pickup.lng),
          dropoffLat: String(payload.dropoff.lat),
          dropoffLng: String(payload.dropoff.lng),
          pickupAddress: parsed.pickup_address ?? null,
          dropoffAddress: parsed.dropoff_address ?? null,
          requestedPickupAt: payload.requested_pickup_at ? new Date(payload.requested_pickup_at) : null,
          pickupWindowMin: payload.pickup_window_minutes ?? 20,
          accessNeeds: payload.access_needs ?? [],
          mobilityAids: payload.mobility_aids ?? [],
          companions: payload.companions ?? 0,
          funding: payload.funding ?? {},
          priceAmount: String(selected.price_amount),
          currency: selected.currency ?? 'AUD',
          events: { create: { type: 'TRIP_CREATED', payload: { quote_id: quote.id, option_id: parsed.option_id } } },
        },
      });

      const adapterKey = selected._adapter_key ?? 'zoomly_manual';
      const adapter = registry.has(adapterKey) ? registry.get(adapterKey) : registry.get('zoomly_manual');

      const booking = await adapter.book({
        tripId: trip.id,
        pickup: { lat: Number(payload.pickup.lat), lng: Number(payload.pickup.lng), address: parsed.pickup_address },
        dropoff: { lat: Number(payload.dropoff.lat), lng: Number(payload.dropoff.lng), address: parsed.dropoff_address },
        requestedPickupAt: payload.requested_pickup_at,
        pickupWindowMin: payload.pickup_window_minutes ?? 20,
        accessNeeds: payload.access_needs ?? [],
        mobilityAids: payload.mobility_aids ?? [],
        companions: payload.companions ?? 0,
        funding: payload.funding ?? {},
        pickupNotes: parsed.pickup_notes,
        rider: { phone: user.phone ?? undefined, name: user.email ?? undefined },
      });

      const nextStatus = booking.status === 'confirmed' ? 'confirmed' : 'pending_provider_confirmation';

      const updated = await app.prisma.trip.update({
        where: { id: trip.id },
        data: {
          status: nextStatus,
          externalBookingRef: booking.externalBookingRef,
          events: { create: { type: 'PROVIDER_BOOKED', payload: booking.raw ?? {} } },
        },
      });

      return TripResponse.parse({
        trip_id: updated.id,
        status: updated.status,
        provider_id: updated.providerId ?? null,
        vehicle_id: updated.vehicleId ?? null,
        driver_id: null,
        external_booking_ref: updated.externalBookingRef ?? null,
        price_amount: updated.priceAmount ? Number(updated.priceAmount) : null,
        currency: updated.currency,
      });
    },

    async getTrip(userSub: string, tripId: string) {
      const user = await app.prisma.user.findUnique({ where: { authSub: userSub } });
      if (!user) throw new createError.Unauthorized('Unknown user');

      const t = await app.prisma.trip.findFirst({ where: { id: tripId, userId: user.id } });
      if (!t) throw new createError.NotFound('Trip not found');

      return TripResponse.parse({
        trip_id: t.id,
        status: t.status,
        provider_id: t.providerId ?? null,
        vehicle_id: t.vehicleId ?? null,
        driver_id: null,
        external_booking_ref: t.externalBookingRef ?? null,
        price_amount: t.priceAmount ? Number(t.priceAmount) : null,
        currency: t.currency,
      });
    },

    async cancel(userSub: string, tripId: string) {
      const user = await app.prisma.user.findUnique({ where: { authSub: userSub } });
      if (!user) throw new createError.Unauthorized('Unknown user');

      const t = await app.prisma.trip.findFirst({ where: { id: tripId, userId: user.id } });
      if (!t) throw new createError.NotFound('Trip not found');

      const u = await app.prisma.trip.update({
        where: { id: t.id },
        data: { status: 'cancelled', events: { create: { type: 'TRIP_CANCELLED', payload: {} } } },
      });

      return TripResponse.parse({
        trip_id: u.id,
        status: u.status,
        provider_id: u.providerId ?? null,
        vehicle_id: u.vehicleId ?? null,
        driver_id: null,
        external_booking_ref: u.externalBookingRef ?? null,
        price_amount: u.priceAmount ? Number(u.priceAmount) : null,
        currency: u.currency,
      });
    },
  };
}

import { Strategy as JwtStrategy, ExtractJwt } from 'passport-jwt';
import passport from 'passport';
import { User } from '../types/User';
import jwt from 'jsonwebtoken';

const JWT_SECRET = process.env.JWT_SECRET || 'dev-secret';

passport.use(
  new JwtStrategy(
    {
      jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(),
      secretOrKey: JWT_SECRET,
      algorithms: ['HS256'],
    },
    (payload, done) => {
      try {
        const user: User = {
          id: payload.sub,
          name: payload.name,
          role: payload.role,
          verified: payload.verified,
        };
        return done(null, user);
      } catch (err) {
        return done(err, false);
      }
    }
  )
);

export const generateJwt = (user: User) =>
  jwt.sign(
    { sub: user.id, name: user.name, role: user.role, verified: user.verified },
    JWT_SECRET,
    { expiresIn: '8h' }
  );

1. Base REST Client for NeonDB
// src/services/neonClient.ts
import fetch from 'node-fetch';

const NEON_API_URL = process.env.NEON_REST_URL!;
const NEON_API_KEY = process.env.NEON_REST_KEY!;

type NeonRequestOptions = {
  method?: 'GET' | 'POST' | 'PATCH' | 'DELETE';
  body?: any;
  headers?: Record<string, string>;
};

export async function neonRequest<T>(path: string, options: NeonRequestOptions = {}): Promise<T> {
  const res = await fetch(`${NEON_API_URL}${path}`, {
    method: options.method ?? 'GET',
    headers: {
      'Content-Type': 'application/json',
      'apikey': NEON_API_KEY,
      ...options.headers,
    },
    body: options.body ? JSON.stringify(options.body) : undefined,
  });

  if (!res.ok) {
    const text = await res.text();
    throw new Error(`NeonDB REST request failed: ${res.status} ${text}`);
  }

  return res.json() as Promise<T>;
}
2. Example: Users Table Integration
// src/services/users.ts
import { neonRequest } from './neonClient';

export type User = {
  id: string;
  authSub: string;
  email?: string;
  phone?: string;
  role?: string;
};

export async function getUserByAuthSub(authSub: string): Promise<User | null> {
  const users = await neonRequest<User[]>(`/users?authSub=eq.${authSub}`);
  return users.length > 0 ? users[0] : null;
}

export async function createUser(user: Partial<User>): Promise<User> {
  const res = await neonRequest<User[]>('/users', { method: 'POST', body: [user] });
  return res[0];
}
3. Integrate into Passport JWT Strategy
// src/auth/jwtStrategy.ts
import passport from 'passport';
import { Strategy as JwtStrategy, ExtractJwt } from 'passport-jwt';
import { getUserByAuthSub, createUser, User } from '../services/users';

const JWT_SECRET = process.env.JWT_SECRET!;

passport.use(
  new JwtStrategy(
    { jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(), secretOrKey: JWT_SECRET, algorithms: ['HS256'] },
    async (payload, done) => {
      try {
        let user = await getUserByAuthSub(payload.sub);
        if (!user) {
          user = await createUser({ authSub: payload.sub, role: 'participant' });
        }
        return done(null, user);
      } catch (err) {
        return done(err as any, false);
      }
    }
  )
);
