# AD.iD Neon central authentication database

This package gives you a Neon-ready PostgreSQL + Prisma foundation for a centralized authentication database for Australian Disapedia.

## What this includes

- Prisma schema for central identity management
- SQL migration you can run against Neon PostgreSQL
- `.env.example` showing pooled and direct Neon connection strings
- `prisma.config.ts` for Prisma CLI using the direct connection
- `src/db/client.ts` using the Neon adapter and pooled runtime connection
- seed script with starter roles

## Intended architecture

- Neon PostgreSQL is the central auth database
- Prisma is the application ORM in a Node/TypeScript auth service
- MediaWiki authenticates against the external identity layer via OIDC
- MediaWiki keeps local wiki users for wiki-specific behavior

## Quick start

1. Create a Neon project and database.
2. Copy the pooled connection string and the direct connection string.
3. Put them into `.env` using the format in `.env.example`.
4. Install dependencies:

```bash
npm install
```

5. Generate Prisma client:

```bash
npx prisma generate
```

6. Apply the migration:

```bash
npx prisma migrate deploy
```

7. Seed starter roles:

```bash
npm run seed
```

## Environment variables

- `DATABASE_URL`: Neon pooled runtime connection string
- `DIRECT_URL`: Neon direct connection string for Prisma CLI and migrations
- `AUTH_PEPPER`: optional extra server-side secret for password hashing workflows
